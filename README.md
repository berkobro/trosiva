# Trosiva

**Set it. Forget it.**

The website for Trosiva: trash bags joined by perforations. Five bags in each disc, so the next bag is ready the moment you pull out the last one.

## Pages

| Page | File |
| --- | --- |
| Home | `index.html` |
| How It Works | `how-it-works.html` |
| About Us | `about.html` |
| Shop (add to cart) | `shop.html` |
| Checkout | `checkout.html` |

## Editing

- **Prices / box sizes:** `assets/site.js`, the `PRODUCTS` list at the top.
- **Team bios and roles:** `about.html` (look for the `TEAM BIO` comment).
- **Colors and fonts:** `assets/style.css`.

It's a plain static site hosted on GitHub Pages, so there's no build step. Edit a file, commit, and the site updates.
